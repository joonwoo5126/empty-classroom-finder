# 빈 강의실 찾기 (Empty Classroom Finder)

> 공강 시간에 쓸 수 있는 빈 강의실을 미리 확인할 수 있도록 돕는 서비스 아이디어

---

## 📌 최종 결과 요약

| 단계 | 내용 |
|---|---|
| **STEP 01. 문제 정의** | 공강이 1～3시간인 학부생은 도서관 열람실이 꽉 찼을 때 쓸 수 있는 빈 강의실을 알 방법이 없어 건물을 돌아다니며 10～20분을 허비한다. 사용 가능한 공간을 미리 확인할 수 있다면 공강을 학습과 휴식에 온전히 쓸 수 있다. |
| **STEP 02. 주요 프롬프트** | ① 문제를 사용자/상황/문제/기대효과로 추상화해 달라고 요청<br>② 검증하지 않은 가정과 해결책이 섞인 표현을 지적해 달라고 요청<br>③ 팀 조건(웹 개발 가능, 하드웨어 예산 없음)을 주고 아이디어 3개를 4개 기준으로 평가해 달라고 요청 |
| **STEP 03. AI 제안 요약** | 문제의 본질을 "강의실 사용 정보가 학생에게 공개되지 않는 정보 비대칭"으로 정리. 해결안으로 A(시간표 기반 조회), B(센서 기반 실시간 점유 표시), C(시간표 조회 + 학생 제보)를 제안하고 B를 가장 혁신적이라고 평가 |
| **STEP 04. 팀의 수정·검토** | 사용자 범위를 "재학생 전체"에서 "공강 1～3시간 학부생"으로 좁힘 / 문제 정의에서 "실시간" 등 해결책 표현 제거 / 직접 경험한 수치(10～20분) 추가 / "시간표상 빈 강의실 = 실제 빈 강의실" 가정을 핵심 위험으로 채택 / AI 추천(B) 대신 실현 가능성을 기준으로 C 선택 |
| **STEP 05. 선택한 방향 및 다음 질문** | **방향:** 한 개 건물을 대상으로 아이디어 C의 MVP 제작<br>**다음 질문:** ① 학교는 강의실 시간표를 어떤 형태로 공개하는가? ② 수업이 없는 강의실에 학생이 자유롭게 들어갈 수 있는가? ③ 학생들이 제보를 남기게 할 동기는 무엇인가? |
